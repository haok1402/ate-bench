### Causal masking at block boundaries

PASS if causal masking is preserved at the block level — each query attends only to blocks whose positions are causally valid (typically blocks at positions `≤ query position`). Credit any of: explicit causal masks added per block, masking the block-score logits before top-k, or block selection that excludes future blocks.
FAIL if no causal handling is added and the architecture would let queries attend to future blocks.
