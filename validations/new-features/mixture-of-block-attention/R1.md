### Block partitioning of K/V

PASS if the diff partitions the K/V sequence into fixed-size blocks. Look for evidence such as `block_size`, `n_blocks` / `num_blocks`, or a `reshape`/`view` into a shape with explicit block dim, e.g., `[..., n_blocks, block_size, ...]`.
FAIL if attention is still computed over the full key sequence with no block partition.
