### Block-level top-k selection

PASS if each query computes a per-block score (typically `query · pooled_block_key` or equivalent gate) and selects the top-k blocks per query. Look for `topk` (or argsort) operating over the block dim, paired with a block-scoring function.
FAIL if there is no per-block gate; for example, if every query attends to all blocks, or if selection is at the token level rather than the block level.
