### Zero-computation expert types

PASS if the diff adds at least one zero-computation expert variant (`zero`, `copy`, or `constant`). The agent may implement only one of the three; that still counts. Look for class names like `ZeroExpert`, `CopyExpert`, `ConstantExpert`, `null_expert`, `identity_expert`, or expert factory entries with these semantics; or class definitions whose forward returns 0, the input unchanged, or a learned constant.
FAIL if no zero-computation variant is added.
