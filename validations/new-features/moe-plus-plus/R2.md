### Router covers regular + zero-compute experts

PASS if the router emits logits over a pool that contains both regular FFN experts AND zero-computation experts, so the router learns to dispatch tokens to the no-op variants. Either layout is acceptable:
- Adding zero experts on top of the existing pool, so the router output dim grows to `n_FFN + n_zero`; OR
- Allocating the zero experts as a subset of an unchanged total expert count, where some slots in `num_experts` are zero-compute and others are regular FFN.
What matters is that the router can dispatch tokens to zero-compute experts at all.
FAIL only if no router logit can ever be assigned to a zero-compute expert (i.e., zero experts exist in code but the router never produces logits for them).
