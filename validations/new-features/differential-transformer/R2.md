### Learnable lambda parameter

PASS if a trainable scalar (or per-head vector) λ is added to the attention module. Either:
- The published parameterisation: four `nn.Parameter`s `λ_q1`, `λ_k1`, `λ_q2`, `λ_k2` plus a `λ_init` schedule, with λ computed as `exp(λ_q1 · λ_k1) − exp(λ_q2 · λ_k2) + λ_init`, OR
- A single `nn.Parameter` for λ.
FAIL if there is no new trainable parameter for the differential coefficient.
