### Differential combination of two attention paths

PASS if the diff computes the attention output as a weighted difference of two parallel attention paths over different (Q, K) splits. Credit any of:
- A literal expression like `softmax(Q1 K1^T) − λ · softmax(Q2 K2^T)`.
- Two distinct calls to the framework's fused attention primitive (e.g., `core_attention`, `mla_flash_attn_func`, `inner_attention`, `flash_attn`) followed by `attn1 − λ · attn2`.
- An equivalent vectorised form using `einsum` / scaled subtraction.
FAIL if there is only one attention path, or no subtraction.
